## ✨ Fitur Utama

- **Rekam layar berbasis browser** — tangkap layar, kamera, dan audio sistem dalam satu langkah. Nol instalasi, jalan di semua browser modern.
- **Kopilot editing AI berbasis bahasa natural** — jelaskan edit yang kamu mau («potong bagian hening, zoom ke tombol, tambahkan kaption») dan dapatkan hasil kualitas studio.
- **Gerakan kamera 3D gaya sinema** — miringkan dan putar klip apa pun dengan preset isometrik, seperti operator kamera sungguhan.
- **Kaption otomatis AI** — transkripsi 100% lokal dengan Whisper + pemeriksaan salah ketik AI, sisipkan dengan 1 klik.
- **Smart tool lokal 0-token** — pemangkasan hening dan zoom klik berjalan lokal dan offline, gratis.
- **Anotasi gaya gambar tangan** — panah sketsa, balon ucapan, sorotan, dan zoom fokus untuk mengarahkan pandangan penonton.
- **Editing multi-track** — layar, kamera, dan narasi di track terpisah; undo apa pun, kapan pun.
- **100% privat sejak desain** — rekamanmu tidak pernah meninggalkan mesin. Tidak ada yang diunggah ke server.
- **Ekspor cepat** — MP4 dan GIF dalam hitungan detik, hingga 4K.

## 🚀 Memulai

1. Buka **[recordel.com/recorder](https://recordel.com/recorder)** — tanpa unduhan, tanpa aplikasi desktop.
2. Pilih yang ingin direkam: layar penuh, jendela, atau tab browser — plus kamera dan audio.
3. Rekam, lalu edit dengan kopilot AI atau manual di timeline multi-track.
4. Ekspor ke MP4 atau GIF, atau bagikan tautannya.

## 🔒 Privasi & BYOK

Recordel bersifat **local-first**: perekaman, transkripsi (Whisper lokal), dan smart tool semuanya berjalan di mesinmu sendiri — tidak ada yang diunggah.

Untuk editing AI, Recordel mendukung **BYOK (Bring Your Own Key)**: sambungkan API key milikmu untuk DeepSeek, Claude, atau OpenAI, atau jalankan sepenuhnya offline dengan **Ollama**.

## ❓ FAQ

**Apakah perlu instal sesuatu?**
Tidak. Rekam dan edit sepenuhnya berjalan di browser.

**Ke mana rekamanku pergi?**
Tidak ke mana-mana. File tetap di perangkatmu — Recordel tidak mengunggah media kamu.

**Provider AI apa yang didukung?**
DeepSeek, Claude, OpenAI dengan API key sendiri (BYOK), atau sepenuhnya offline dengan Ollama.
