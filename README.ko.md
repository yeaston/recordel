## ✨ 주요 기능

- **브라우저 기반 화면 녹화** — 화면·카메라·시스템 오디오를 한 번에 캡처. 설치 없이 어떤 최신 브라우저에서든 동작.
- **자연어 AI 편집 코파일럿** — "무음 잘라내고, 버튼에 줌, 자막 추가"처럼 원하는 편집을 말하면 스튜디오급 결과물로.
- **영화 같은 3D 카메라 무빙** — 어떤 클립이든 기울이고 회전 가능. 아이소메트릭 프리셋 내장.
- **AI 자동 자막** — 100% 로컬 Whisper 음성 인식 + AI 오타 검수, 원클릭 자막 삽입.
- **토큰 0 소모 로컬 스마트 도구** — 무음 트리밍·클릭 줌은 로컬에서 오프라인 실행, 무료.
- **손그림 스타일 주석** — 스케치 화살표, 말풍선, 스포트라이트, 포커스 줌으로 시선 유도.
- **멀티트랙 편집** — 화면·카메라·내레이션이 각각 독립 트랙으로, 모든 작업 언제든 되돌리기 가능.
- **100% 프라이버시 설계** — 녹화물은 절대 기기를 벗어나지 않습니다. 서버 업로드 없음.
- **빠른 내보내기** — MP4 / GIF를 몇 초 만에, 최대 4K 지원.

## 🚀 시작하기

1. **[recordel.com/recorder](https://recordel.com/recorder)** 열기 — 다운로드도, 데스크톱 앱도 필요 없습니다.
2. 녹화 대상 선택: 전체 화면·창·브라우저 탭, 카메라와 오디오 동시 녹화 가능.
3. 녹화 후 AI 코파일럿 또는 멀티트랙 타임라인에서 직접 편집.
4. MP4 / GIF로 내보내거나 링크를 공유하세요.

## 🔒 개인정보 & BYOK

Recordel은 **로컬 퍼스트**: 녹화, 전사(로컬 Whisper), 스마트 도구가 모두 사용자 기기에서 실행되며 업로드는 없습니다.

AI 편집은 **BYOK(내 키 사용)** 지원: DeepSeek, Claude, OpenAI API 키를 연결하거나 **Ollama**로 완전 오프라인 실행도 가능.

## ❓ 자주 묻는 질문

**설치가 필요한가요?**
아니요. 녹화와 편집 모두 브라우저에서 완결됩니다.

**녹화 파일은 어디로 가나요?**
어디로도 가지 않습니다. 파일은 기기에 남고, Recordel은 미디어를 업로드하지 않습니다.

**지원 AI 제공사는?**
BYOK(내 API 키)로 DeepSeek, Claude, OpenAI 사용 가능. Ollama로 완전 오프라인도 가능합니다.
