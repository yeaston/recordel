## ✨ 主な機能

- **ブラウザ完結の画面録画** — 画面・カメラ・システム音声をワンステップでキャプチャ。インストール不要、モダンブラウザならどこでも動作。
- **自然言語 AI 編集コパイロット** — 「無音をカットして、ボタンにズーム、字幕を追加」と伝えるだけで、スタジオ品質の編集結果に。
- **映画のような 3D カメラワーク** — どのクリップでもチルト・回転が可能。アイソメトリックプリセット付き。
- **AI 自動字幕** — 100% ローカル Whisper 音声認識 + AI 誤字チェック、ワンクリックで字幕を反映。
- **0 トークンのローカルスマートツール** — 無音トリミング・クリックズームはローカルでオフライン実行、無料。
- **手描き風アノテーション** — 手描き矢印、吹き出し、スポットライト、フォーカスズームで視線を誘導。
- **マルチトラック編集** — 画面・カメラ・ナレーションを独立トラックで管理。全操作をいつでも取り消し可能。
- **100% プライバシー設計** — 録画データは端末の外に出ません。サーバーへのアップロードは一切なし。
- **高速エクスポート** — MP4 / GIF を数秒で書き出し、最大 4K 対応。

## 🚀 はじめに

1. **[recordel.com/recorder](https://recordel.com/recorder)** を開く — ダウンロード不要、デスクトップアプリも不要。
2. 録画対象を選択：全画面・ウィンドウ・ブラウザタブ、カメラと音声も同時に。
3. 録画後、AI コパイロットまたはマルチトラックタイムラインで手動編集。
4. MP4 / GIF でエクスポート、またはリンクを共有。

## 🔒 プライバシーと BYOK

Recordel は**ローカルファースト**：録画、文字起こし（ローカル Whisper）、スマートツールはすべて端末上で動作し、アップロードは行いません。

AI 編集は **BYOK（自分の API キー）** に対応：DeepSeek、Claude、OpenAI のキーを接続、または **Ollama** で完全オフライン実行も可能。

## ❓ よくある質問

**インストールは必要ですか？**
不要です。録画も編集もすべてブラウザ上で完結します。

**録画データはどこへ？**
どこにも行きません。ファイルは端末に残り、Recordel はメディアをアップロードしません。

**対応している AI プロバイダーは？**
BYOK（自分の API キー）で DeepSeek、Claude、OpenAI を利用可能。Ollama なら完全オフラインでも動作します。
