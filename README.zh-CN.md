## ✨ 核心功能

- **浏览器端录屏** — 一步捕获屏幕、摄像头与系统声音，零安装，任何现代浏览器可用。
- **自然语言 AI 剪辑副驾驶** — 用一句话描述你想要的剪辑（"去掉静音、给按钮加缩放、加字幕"），得到专业级成片。
- **电影感 3D 运镜** — 任意片段可倾斜、旋转，内置等轴预设，像真正的运镜师一样呈现画面。
- **AI 自动字幕** — 100% 本地 Whisper 语音转文字，附 AI 错别字校对，一键回填字幕。
- **0-token 本地智能工具** — 静音裁剪、鼠标点击缩放全部在本地离线运行，免费使用。
- **手绘风格标注** — 涂鸦箭头、气泡框、聚光灯与焦点缩放，精准引导观众视线。
- **多轨编辑** — 屏幕、摄像头、旁白各占独立轨道，随时撤销任何操作。
- **100% 隐私设计** — 录制内容永不离开你的设备，服务器不做任何上传。
- **极速导出** — 秒级导出 MP4 / GIF，最高支持 4K。

## 🚀 快速开始

1. 打开 **[recordel.com/recorder](https://recordel.com/recorder)** — 无需下载，没有桌面端。
2. 选择录制对象：全屏、窗口、浏览器标签页，可同时开启摄像头与声音。
3. 录制完成后，用 AI 副驾驶或多轨时间线手动剪辑。
4. 导出 MP4 / GIF，或直接分享链接。

## 🔒 隐私与 BYOK

Recordel 是**本地优先**的产品：录制、转写（本地 Whisper）与智能工具全部在你的设备上运行，不做任何上传。

AI 剪辑支持 **BYOK（自带 Key）**：接入你自己的 DeepSeek、Claude、OpenAI API Key，或用 **Ollama** 完全离线运行。

## ❓ 常见问题

**需要安装任何东西吗？**
不需要。录制与剪辑完全在浏览器中完成。

**我的录制文件会去哪里？**
哪儿也不去。文件始终留在你的设备上，Recordel 不上传任何媒体内容。

**支持哪些 AI 服务商？**
通过自带 API Key（BYOK）使用 DeepSeek、Claude、OpenAI，或用 Ollama 完全离线运行。
