## ✨ الميزات الرئيسية

- **تسجيل الشاشة في المتصفح** — التقط الشاشة والكاميرا وصوت النظام في خطوة واحدة. بدون تثبيت، ويعمل على أي متصفح حديث.
- **مساعد تحرير بالذكاء الاصطناعي بلغة طبيعية** — صف التعديل الذي تريده («احذف الصمت، كبّر الزر، أضف ترجمة») واحصل على نتيجة بجودة الاستوديو.
- **حركات كاميرا ثلاثية الأبعاد بأسلوب سينمائي** — أَمِل وأدِر أي مقطع مع إعدادات أيزومترية جاهزة، مثل مصوّر سينمائي حقيقي.
- **ترجمة تلقائية بالذكاء الاصطناعي** — تفريغ صوتي 100% محلي عبر Whisper مع تدقيق إملائي بالذكاء الاصطناعي، وإدراج بنقرة واحدة.
- **أدوات ذكية محلية بلا رموز (0 token)** — قص الصمت وتكبير نقرة الفأرة يعملان محليًا وبدون اتصال، مجانًا.
- **تعليقات توضيحية بأسلوب الرسم اليدوي** — أسهم مرسومة، فقاعات حوار، أضواء بؤرية وتكبير للتركيز لتوجيه انتباه المشاهد.
- **تحرير متعدد المسارات** — الشاشة والكاميرا والتعليق الصوتي على مسارات مستقلة؛ تراجع عن أي شيء في أي وقت.
- **خصوصية 100% بالتصميم** — تسجيلاتك لا تغادر جهازك أبدًا. لا يُرفع أي شيء إلى أي خادم.
- **تصدير سريع** — MP4 وGIF في ثوانٍ، حتى 4K.

## 🚀 البدء السريع

1. افتح **[recordel.com/recorder](https://recordel.com/recorder)** — لا تنزيل ولا تطبيق مكتبي.
2. اختر ما تريد تسجيله: ملء الشاشة أو نافذة أو تبويب، مع الكاميرا والصوت.
3. سجّل، ثم حرّر بمساعد الذكاء الاصطناعي أو يدويًا على الخط الزمني متعدد المسارات.
4. صدّر بصيغة MP4 أو GIF، أو شارك الرابط.

## 🔒 الخصوصية و BYOK

Recordel يعمل بمبدأ **ال local-first**: التسجيل والتفريغ الصوتي (Whisper محلي) والأدوات الذكية تعمل كلها على جهازك — لا يُرفع شيء.

للتحرير بالذكاء الاصطناعي، يدعم Recordel **BYOK (أحضر مفتاحك الخاص)**: اربط مفاتيح API الخاصة بك من DeepSeek أو Claude أو OpenAI، أو اعمل بالكامل دون اتصال عبر **Ollama**.

## ❓ الأسئلة الشائعة

**هل أحتاج إلى تثبيت شيء؟**
لا. التسجيل والتحرير يتمان بالكامل في المتصفح.

**إلى أين تذهب تسجيلاتي؟**
إلى أي مكان. تبقى الملفات على جهازك — Recordel لا يرفع وسائطك.

**ما مزودو الذكاء الاصطناعي المدعومون؟**
DeepSeek وClaude وOpenAI بمفتاح API الخاص بك (BYOK)، أو بالكامل دون اتصال عبر Ollama.
