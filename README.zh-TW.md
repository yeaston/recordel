## ✨ 核心功能

- **瀏覽器端錄屏** — 一步擷取螢幕、攝影機與系統聲音，零安裝，任何現代瀏覽器可用。
- **自然語言 AI 剪輯副駕駛** — 用一句話描述你想要的剪輯（「去掉靜音、給按鈕加縮放、加字幕」），得到專業級成片。
- **電影感 3D 運鏡** — 任意片段可傾斜、旋轉，內建等軸預設，像真正的運鏡師一樣呈現畫面。
- **AI 自動字幕** — 100% 本地 Whisper 語音轉文字，附 AI 錯字校對，一鍵回填字幕。
- **0-token 本地智慧工具** — 靜音裁剪、滑鼠點擊縮放全部在本地離線執行，免費使用。
- **手繪風格標註** — 塗鴉箭頭、氣泡框、聚光燈與焦點縮放，精準引導觀眾視線。
- **多軌編輯** — 螢幕、攝影機、旁白各佔獨立軌道，隨時復原任何操作。
- **100% 隱私設計** — 錄製內容永不離開你的裝置，伺服器不做任何上傳。
- **極速匯出** — 秒級匯出 MP4 / GIF，最高支援 4K。

## 🚀 快速開始

1. 開啟 **[recordel.com/recorder](https://recordel.com/recorder)** — 無需下載，沒有桌面端。
2. 選擇錄製對象：全螢幕、視窗、瀏覽器分頁，可同時開啟攝影機與聲音。
3. 錄製完成後，用 AI 副駕駛或多軌時間線手動剪輯。
4. 匯出 MP4 / GIF，或直接分享連結。

## 🔒 隱私與 BYOK

Recordel 是**本地優先**的產品：錄製、轉寫（本地 Whisper）與智慧工具全部在你的裝置上執行，不做任何上傳。

AI 剪輯支援 **BYOK（自帶 Key）**：接入你自己的 DeepSeek、Claude、OpenAI API Key，或用 **Ollama** 完全離線執行。

## ❓ 常見問題

**需要安裝任何東西嗎？**
不需要。錄製與剪輯完全在瀏覽器中完成。

**我的錄製檔案會去哪裡？**
哪裡也不去。檔案始終留在你的裝置上，Recordel 不上傳任何媒體內容。

**支援哪些 AI 服務商？**
透過自帶 API Key（BYOK）使用 DeepSeek、Claude、OpenAI，或用 Ollama 完全離線執行。
